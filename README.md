## 🌟 معرفی پروژه

**فال‌گیر (FalGir)** یک وب‌اپلیکیشن مستقل، سبک و بسیار چشم‌نواز است که آیین سنتی تفأل به دیوان خواجه شمس‌الدین محمد حافظ شیرازی (لسان‌الغیب) را در قالبی تعاملی و مدرن بازآفرینی می‌کند. این پروژه با تلفیق هنر سنتی کتاب‌آرایی ایرانی (تذهیب زرین، ترنج، چرم عنابی طلاکوب و قلم فاخر ایران‌نستعلیق) با مدرن‌ترین قابلیت‌های وب (CSS 3D Transforms و Web Audio API) توسعه یافته است.

پروژه به صورت **Pure Vanilla (بدون هیچ فریم‌ورک، کتابخانه خارجی یا ابزار بیلد)** پیاده‌سازی شده و با حجم بسیار اندک، سرعت اجرایی بالا و سازگاری بی‌نقص با انواع نمایشگرها (از گوشی‌های موبایل تا صفحات بزرگ دسکتاپ) اجرا می‌شود.

## ✨ ویژگی‌های کلیدی

### ۱. آیین گشودن و تورق دیوان (Divination Ritual Sequence)
- **فاز ۱ (نیت و آرامش):** با کلیک روی کتاب یا دکمهٔ تفأل، کتاب با نورپردازی ملایم در فضا اوج گرفته و هم‌زمان نوای معنوی کاسهٔ تبتی با فرکانس ۴۳۲ هرتز طنین‌انداز می‌شود.
- **فاز ۲ (تورق پیوسته صفحات):** جلد چرمی دیوان به نرمی گشوده شده و برگ‌های مصور دیوان با ترتیب دقیق شماره‌گذاری غزل‌ها به صورت سه‌بعدی و پی‌درپی ورق می‌خورند.
- **فاز ۳ (کتیبهٔ شعر):** نسخهٔ خطی غزل با کادر تذهیب دوجداره، شمسه و تذهیب لعل عنابی آشکار شده و ابیات با خط اصیل نستعلیق خط‌به‌خط ظاهر می‌شوند.
- **فاز ۴ (تعبیر لسان‌الغیب):** پیام و تعبیر معنوی و کاربردی غزل در کارتی با بافت کاغذ کهن به کاربر پیشکش می‌گردد.

### ۲. تایپوگرافی اصیل و متقارن
- رندر متون اشعار با وب‌فونت بهینه‌شدهٔ **ایران‌نستعلیق (IranNastaliq)** در قالب مصرع‌های متقارن سنتی.
- استفاده از فونت خوانا و چشم‌نواز **وزیرمتن (Vazirmatn)** برای رابط کاربری، جستجو و تعابیر.

### ۳. دیتابیس کامل و تصحیح‌شدهٔ ۴۹۵ غزل
- شامل متن کامل تمامی ۴۹۵ غزل دیوان حافظ بر اساس نسخه‌های معتبر همراه با تعبیر جامع برای تک‌تک غزل‌ها در فایل `falnama.json`.
- برطرف‌سازی کامل خلأهای متنی و تعابیر مفقود برای تمام غزل‌ها (شامل غزل‌های ۴۵۲ و ۴۶۰).

### ۴. ابزارهای تعاملی پیشرفته
- 🔍 **جستجو و تفأل مستقیم:** امکان جستجوی بلادرنگ بر اساس شمارهٔ غزل یا واژگان کلیدی در متن ابیات.
- 📜 **آداب و رسم تفأل:** مودال اختصاصی شامل تاریخچه لقب لسان‌الغیب و دعای سنتی پیش از گشودن دیوان.
- 📋 **کپی با فرمت شکیل:** کپی آسان متن شعر و تعبیر در حافظه کلیپ‌بورد همراه با پیام اطلاع‌رسانی روان (Toast).
- 📤 **اشتراک‌گذاری هوشمند:** بهره‌گیری از **Web Share API** جهت ارسال مستقیم فال در تلگرام، واتس‌اپ و شبکه‌های اجتماعی در موبایل.
- 🖨️ **چاپ به سبک نسخه‌های کهن خطی:** استایل اختصاصی پرینت (Print Stylesheet) بدون عناصر زائد کاربری و آماده برای پرینت یا ذخیره به صورت PDF فاخر.

### ۵. بهینه‌سازی کامل موبایل (Mobile-First)
- پیشگیری اصولی از هرگونه اسکرول افقی (Zero Horizontal Overflow).
- هماهنگی خودکار ابعاد دیوان سه‌بعدی و کادر اشعار با عرض انواع نمایشگرها.

## 🎵 جلوه‌های صوتی و مهندسی صدا (Web Audio API)

یکی از وجوه تمایز فنی پروژه **فال‌گیر**، سنتز تمام صداها به صورت کاملاً الگوریتمی در محیط مرورگر است؛ **بدون لود حتی یک بایت فایل MP3 یا WAV صوتی**:

1. **نوای کاسهٔ تبتی (Tibetan Singing Bowl):**
   - تولید هارمونیک‌های عرفانی روی فرکانس پایهٔ ۴۳۲ هرتز به همراه اُورتون‌های ضربانی با استفاده از نوسان‌سازهای سینوسی چندگانه و میرایی نمایی (Exponential Gain Decay).
2. **صدای خش‌خش ورق خوردن کتاب (Page Rustle):**
   - تولید با نویز سفید الگوریتمی (AudioBuffer Noise)، هدایت از طریق فیلتر میان‌گذر (Bandpass Filter) با پیک فرکانسی ۱۲۰۰ هرتز و پاکت موجی کوتاه.
3. **آکورد افشای غزل (Celestial Harp Chime):**
   - زنجیره‌ای از فرکانس‌های پنتاگونال ملایم در لحظهٔ نمایان شدن کتیبهٔ شعر.
4. **کلید کنترل صدا:** قابلیت قطع/وصل فوری صدا با ذخیره‌سازی وضعیت کاربر در `localStorage`.

## 🎨 طراحی سه‌بعدی و هویت بصری

دیوان طراحی‌شده در این پروژه یک حجم هندسی سه‌بعدی واقعی با فناوری CSS 3D است:
- **جلد چرم عنابی طلاکوب:** همراه با ترنج مرکزی، سرترنج‌های اسلیمی، شمسهٔ ۱۲پر و کتیبهٔ نام دیوان با گرادیان‌های برداری SVG.
- **عطف سنتی (Spine):** عطف شیرازه‌دوزی شده با بندهای برجسته و نام زرین حافظ در سمت راست (سازگار با کتاب‌های راست‌به‌چپ فارسی).
- **لبه‌های طلایی اوراق (Gilded Page Edges):** بافت خطی چندلایه که در حالت بسته بودن کتاب، ضخامت دیوان کهن را تداعی می‌کند.
- **آستر ابروباد و نشان داخلی (Endpaper):** طراحی داخلی الهام‌گرفته از تجلیدهای صفوی و قاجاری.

## 💻 راهنمای نصب و اجرای محلی

از آنجا که پروژه کاملاً مستقل از سرور است، اجرای آن در چند ثانیه امکان‌پذیر است:

### روش ۱: کلون کردن مخزن
```bash
# ۱. کلون کردن مخزن
git clone https://github.com/ramin-mahmoodi/FalGir.git

# ۲. ورود به پوشه پروژه
cd FalGir
```

### روش ۲: اجرای یک وب‌سرور سبک محلی
به دلیل بارگذاری فایل `falnama.json` از طریق متد `fetch`، مرورگرها به یک وب‌سرور محلی نیاز دارند (برای جلوگیری از خطای CORS در حالت `file://`):

**با استفاده از Python (پیشنهادی):**
```bash
python -m http.server 8000
```
سپس آدرس `http://localhost:8000` را در مرورگر خود باز کنید.

**یا با استفاده از Node.js:**
```bash
npx serve .
```

**یا با اکستنشن Live Server در VS Code:**
روی فایل `index.html` راست‌کلیک کرده و گزینهٔ **Open with Live Server** را انتخاب کنید.

| کلید | عملکرد |
| :--- | :--- |

## 🚀 انتشار روی GitHub Pages

برای استقرار این سامانه روی سرویس رایگان **GitHub Pages**:

1. وارد تنظیمات ریپازیتوری خود در گیت‌هاب شوید (**Settings**).
2. از منوی کناری به بخش **Pages** بروید.
3. در قسمت **Build and deployment**:
   - بخش **Source** را روی `Deploy from a branch` تنظیم کنید.
   - شاخه (Branch) را روی `main` و مسیر را روی `/ (root)` قرار دهید.
4. دکمهٔ **Save** را بزنید. پس از ۱ الی ۲ دقیقه، دیوان حافظ شما در آدرس زیر در دسترس خواهد بود:
   ```text
   https://<your-username>.github.io/FalGir/
   ```
